I added input validation to `add` in `app.py`, but I couldn't run it. The test command needed approval, which this session can't give.

`add(a, b)` now raises `TypeError` if either argument isn't an `int` or `float`. Strings like `"1"`, `None`, lists and booleans are all rejected. I excluded booleans on purpose, because Python treats `True` as the number 1. The error message names the bad argument and its type.

To check it yourself, run this from the case directory:

```
python -c "from app import add; print(add(1,2.5)); add('1',1)"
```

The first call should print `3.5`. The second should raise `TypeError: a must be a number, got str`.
